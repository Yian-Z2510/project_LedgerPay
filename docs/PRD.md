Project Overview
LedgerPay is a mini payment gateway simulator built with Java Spring Boot. 

The project simulates a basic payment lifecycle, including payment creation, payment status tracking, refunds, and webhook notifications.

Problem Statement 
This project is built to demonstrate backend product thinking, API design, payment domain understanding, and AI-assisted software development workflow.

Target Users
Developer users who integrate with the payment API

Internal operations users who need to check payment and refund status

MVP Scope
This MVP will include:

Payment 

Create payment

Query payment status

Simulate payment success or failure

Notification 

Refund

Create partial refund

Create full amount refund

Query refund status

Simulate webhook notification

Non-functional 

Basic API documentation 

Unit test for core service lpgic

Out of Scope
THis MVP does not include:

Real bank/card network integration 

Real money movement

User authentication 

Frontend UI

Production-level security

Multi-currency settlement 

Complex risk/fraud engine

Completion Criteria
The project is considered complete when:

Core payment and refund APIs are implemented

Payment lifecycle can be tested through Postman or curl

Webhook simulation works

Main business logic has unit tests

README explains how to run and test the project
